# CPU のクロック切り替え（段階2）：タスクバー常駐アプリ SwitchClock

## 中身

| ファイル | 内容 |
|---|---|
| `SwitchClock.exe` | 通知領域に常駐するアプリ。ソースは `..\SwitchClockTray\src\SwitchClock.cs` |

- **前提:** 段階1のドライバー（`switchcpu.sys` v2）が入っていること。
- **権限:** 管理者として実行する必要はない。ドライバーが、ログインしているユーザーにも切り替えを許している。
- **作り:** .NET Framework 4 の C#（WinForms）。Win10 ARM64 では x86 のエミュレーションで動く。

## 使い方

1. **`SwitchClock.exe` を Switch にコピーする。** 例: `C:\SwitchWOA\Clock\SwitchClock.exe`。
2. **ダブルクリックで起動する。** 通知領域に、今のクロックを GHz で表示した小さなアイコンが出る（例: `1.0`）。
   - 見当たらないときは、通知領域の「^」（隠れているアイコン）を開く。アイコンをタスクバーへドラッグすると、常に表示される。
3. **アイコンをクリックすると、メニューが出る。** 左右どちらのクリックでもよい。
   - **一番上:** 今の状態（例: `1209.6 MHz / 1093 mV / SoC 42℃`）。
   - **プロファイルの一覧:** 選んだものにチェックが付き、今動いているものは太字になる。
   - **「ログイン時に起動」:** チェックすると、ログインしたときに自動で起動する。
   - **「終了」:** アプリを閉じる。クロックは、そのときの値のまま変わらない。
4. **アイコンの色:**

| 色 | 意味 |
|---|---|
| 緑 | 通常のプロファイル |
| 黄 | 試験的なプロファイル |
| 赤 | 温度で標準に制限中（SoC 80 ℃ 以上。70 ℃ 未満に戻ると、選んでいたプロファイルに戻る） |
| 灰色の「?」 | ドライバーに接続できない |

## 画面の明るさ（2026-10-25 追加）

- メニューに「画面の明るさ」を追加した。10〜100% から選ぶ。
- **必要なもの:** UEFI R376 と、ファンのドライバー v2（1.0.0.2）。ドライバーが古いときは、この項目は表示されない。
- 選んだ明るさはドライバーが保存して、次に起動したときに戻す。

## 起動したときの動き

- 前回選んだプロファイルに戻す。ただし、**試験的なもの（最大、定格最大）は戻さない。** 不安定なときに、起動するたびに固まるのを防ぐため。
- 試験的なプロファイルを選ぶと、確認の画面が出る。

## 結果（2026-10-25、ユーザー報告）

- **メニューは文字化けせずに表示された。**
- **「定格最大」（1766.4 MHz / 1225 mV）が、普通に動いた。** メニューの一番上は `1766.4 MHz / 1225 mV / SoC 44°C` だった。
- **未確認:** 再起動したときに、前回のプロファイルに戻るか。

## 結果を共有してほしいこと

- アイコンとメニューが正しく表示されるか（文字化けしないか）。
- プロファイルを切り替えると、アイコンの数字と一番上の状態が変わるか。
- 「ログイン時に起動」をチェックして再起動したとき、前回のプロファイルに戻るか。
